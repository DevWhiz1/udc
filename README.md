Getting Started

Follow these steps to run the project locally.

Prerequisites
Node.js
npm (included with Node.js)
Installation
Clone the repository:
   git clone <repository-url>

Navigate to the project directory:
   cd <project-folder>

Install dependencies:
   npm install

Environment Setup

If your application requires environment variables, create a .env.local file in the root directory and add the required configuration.

API_KEY=your_api_key_here


Replace the example value with your actual API key if required by your application.

Run the Application

Start the development server:

npm run dev


Open the local URL displayed in your terminal to view the application.

Available Scripts
npm run dev — Start the development server.
npm run build — Build the application for production.
npm run preview — Preview the production build.
